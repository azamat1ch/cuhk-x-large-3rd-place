# Order, repetitions and ambiguous bundles

## Order from events

Use the principal demonstrated episode of each action as the working sequence
convention. This is an experimental project convention, not verified official
annotation policy. When an action repeats, prefer a clearly self-contained enactment
with directed attention, established action posture/contact and a completed return
over a brief embedded gesture. A later sustained wrist inspection may therefore
determine the sequence even when an earlier short check is real. Duration supports
this comparison but does not decide it alone. If episodes are equally established,
use the first. Preserve every real occurrence in the timeline and explicitly note
when selecting a later episode changes the first-occurrence order. Do not relabel
an early action as absent or aborted to justify the chosen order.

Timestamp the disputed pair directly using before/during/after frames. If action
intervals overlap, compare supported onset and explain limits; do not invent a gap.
A gesture first visible at a sampled frame may have begun earlier. A hidden event
suggested by an ordering question remains time-uncertain; a convenient empty slot
is not visual proof. If an alternate occurrence changes the order, describe that
ambiguity and still select the best-supported permitted string.

Separate persistent states from action episodes. Already seated is not sitting
down; already wearing headphones does not establish listening onset. Later utensil
use cannot by itself timestamp grabbing it. Consult the action family for the
specific transition instead of applying one generic onset heuristic to all actions.

Compare repeated candidate gestures using gaze, target, posture/contact and
completion. Distinguish incidental motion from real action, then separately decide
which real episode is the principal demonstration. State the observed basis for
that choice; do not substitute a familiar routine or convenient answer order.

## Bundles describe a coherent account

Assign candidate labels to episodes before comparing bundles. If the same obscured
movement could be phone use or writing, it is not evidence that both happened.
A bundle requiring both needs separately supported activity, possibly overlapping
but physically compatible. Similarly, dish cleaning and table wiping require
separate evidence when both appear in one option.

Compare the bundles' distinguishing actions against their required physical
patterns. Missing a tiny object is weaker counterevidence than observing a
contradictory hand destination or inventing an additional episode. Apply equal
standards: do not demand a fully resolved object for one option while accepting
vague handling for another. Exclusion can select an answer without identifying
every hidden object; state what remains uncertain.

More than one bundle can genuinely describe observed actions because bundles are
not necessarily exhaustive. There is no general rule to choose the longer bundle,
the most typical routine, or whichever matches another performance. Check exact
wording and competing interpretations; if ambiguity remains, return the best
supported permitted choice with its strongest alternative and the unresolved reason.

## Manner boundary

Normal answers identify what happened; the emotion scenario concerns how the whole
sequence was performed. Adjectives are not three fixed speed classes. Total duration,
a maintained posture, action count, a pause or looking down alone cannot establish
calmness, attentiveness or hurry. Do not invent manner to complete a normal scene,
or transfer action order or manner from another person's enactment.
