# One recording, one supported account

Read every question before viewing. Questions identify useful distinctions and may
target different episodes or omit supported actions. Keep one scene and event ledger,
then choose each answer from its actual permitted options. Name a room or functional
area only when visible features support it. Scene summaries compress the supported
timeline; they must not add facts or strengthen uncertain interpretations. Physical
continuity and plausible object use can test an interpretation, but cannot supply
unseen steps to complete a familiar routine.

| Question category | What to return and what it means |
| --- | --- |
| HARn-single | One letter for the offered action occurring in the recording. The benchmark name does not turn it into next-action prediction. |
| HARn-object_interaction | One letter for the object involved in the specified interaction. Use the objects skill when names are ambiguous. |
| HAU-single | One letter for the supported offered action; other actions may also occur. |
| HAU-multi | Every supported offered action as a nonempty unordered subset; return letters alphabetically. Similar is not identical. |
| HAU-combination | One letter for a coherent bundle of actions; the bundle need not exhaust the recording. |
| HAU-sequence | All offered action letters once in chronological order. Letter order in the question is not event order. |
| HAU-emotion | One letter describing how the whole routine is performed. This belongs to the separate emotion scenario, not an extra action in normal investigations. |

Use four distinguishable supports in concise evidence: directly observed feature,
question-derived presence hint, demonstrated training naming convention, and
exclusion of incompatible options. A strong relative choice can have weak direct
visibility. Do not convert a good inference into a claim that an object was seen.

An ordering question presupposes its listed actions and thus gives strong presence
hints for other questions on the same recording. It does not locate hidden acts,
prove their order or list every activity. Repeated wording in ordinary options and
the union of combination bundles do not establish presence. Do not ignore clearly
conflicting observations just because the question suggests an action.

Resolve alternative explanations of one episode once and reuse the result across
questions. An action accepted in one answer should not be denied in another without
a scope/wording reason. Distinct offered sets can legitimately produce different
selected subsets. Do not collect mutually incompatible labels from separate views.

Read [temporal-and-combinations](references/temporal-and-combinations.md) for repeated
occurrences, overlaps, uncertain onset and competing defensible bundles.
