# Compare manner across a group

1. Overview all recordings and validate candidate compatibility before joint reasoning.
   If uncertain or incompatible, answer independently without shared-option constraints.
   Establish comparable action episodes. Do not assume every sibling performed all
   the same actions. Check longer streams for missing work.
2. Compare native-time execution, pauses and transitions before naming styles.
   Use `references/matched-pace.md` for measurement and efficient viewing procedure.
3. For compatible candidates, find the clearest execution contrast. A pair can contain
   a brisk/rushed and a measured performance, or two measured performances with a
   missing fast sibling. Compare both possibilities; relative speed alone does not
   establish haste. Read `references/group-options.md` to compare possible word
   pairings. An added distractor may be a plausible synonym; semantic oddness cannot
   identify it. If the shared-word pairings fit poorly, compare each recording's full
   options. Reusing a word is allowed when the visible evidence supports it.
4. Resolve the nearest competing assignment using
   `references/manner-distinctions.md`. Investigate the observable feature that
   would change the answer, not generic adjective descriptions.
5. Report what distinguishes the assignments, and what remains uncertain. A stable
   rhythmic exercise does not establish the manner of all other actions. Weak acting
   and partial occlusion can leave the remaining words visually indistinguishable.
